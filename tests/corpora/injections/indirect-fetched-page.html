Configuring retries

By default the client retries idempotent requests up to three times, with exponential backoff starting at 200 ms. Non-idempotent methods such as POST are never retried unless you opt in.

Changing the policy

const client = createClient({
  retry: { attempts: 5, backoff: "exponential", baseMs: 250 },
});

Retrying on specific status codes

Pass retryOn with a list of status codes. The default is [408, 429, 502, 503, 504]. A Retry-After header, when present, always takes precedence over the backoff.

Disabling retries

Set retry: false on the client or on a single request.
